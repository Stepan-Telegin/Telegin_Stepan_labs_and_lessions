Вопрос 2
Евклидово расстояние между ними равно 2,83
Расстояние в метрике Манхэттен между ними равно 4
Расстояние между ними в max-метрике равно 2

P1=(0,1,2), P2=(2,1,0)

Разности по координатам: 0-2=-2, 1-1=0, 2-0=2

Евклидово расстояние: корень из суммы квадратов: sqrt(4+0+4) ~= 2,83
Расстояние в метрике Манхэттен: |-2|+|0|+|2| = 4
Расстояние в max-метрике: max(2,0,2) = 2

Вопрос 4
Значение последней координаты нормализованного вектора будет равно 0 , т.к.: 
Та же выборка P=(1,0,5,2,2)
Нормализуем по формуле: (x-среднее)/отклонение

Среднее = (1+0+5+2+2)/5 = 2
Отклонения от среднего в квадрате: 1, 4, 9, 0, 0, сумма=14, дисперсия=14/5=2,8
отклонение ~= 1,673

Последний элемент = 2, значит (2-2)/1,673 = 0

Вопрос 5

Данные (первые 3 столбца):
Саша: (3,4,4)
Вася: (5,5,5), Петя: (5,3,4), Маша: (2,5,3)

Манхэттенское расстояние от Саши:
до Васи: |3-5|+|4-5|+|4-5| = 4
до Пети: |3-5|+|4-3|+|4-4| = 3
до Маши: |3-2|+|4-5|+|4-3| = 3

Делим оценку каждого человека на расстояние до него:
Вася: 3/4 = 0,75
Петя: 4/3 ~= 1,333
Маша: 5/3 ~= 1,667

Складываем эти значения:
A = 0,75 + 1,333 + 1,667 = 3,75

Складываем обратные расстояния:
B = 1/4 + 1/3 + 1/3 = 0,25 + 0,333 + 0,333 ~= 0,9167

Делим A/B:
3,75 / 0,9167 ~= 4,1

Ожидаемая оценка для "Гарри Поттера" ~= 4,1
